# systematic-debugging

1. Define síntoma exacto.
2. Determina alcance/entorno.
3. Reproduce si es posible.
4. Recopila logs/errores.
5. Formula hipótesis.
6. Busca evidencia.
7. Localiza causa raíz.
8. Corrige lo mínimo.
9. Verifica caso original.
10. Verifica regresiones cercanas.
