# accessibility-review

Comprueba según aplique: landmarks, headings, teclado, focus, orden de foco, labels, errores, alt, contraste, color, botones/enlaces, modales/menús, zoom/reflow.

Si hay WCAG contractual, documenta nivel y alcance.
