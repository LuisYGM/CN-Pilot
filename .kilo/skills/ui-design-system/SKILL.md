# ui-design-system

Define solo lo necesario para el alcance: tipografía, colores, spacing, radios, sombras, containers, botones, forms, cards, navegación, estados, breakpoints y restricciones de accesibilidad.

No conviertas una landing sencilla en una librería empresarial.
