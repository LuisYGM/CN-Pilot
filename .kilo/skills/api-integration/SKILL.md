# api-integration

1. Identifica contrato/versión.
2. No inventes endpoints.
3. Separa credenciales.
4. Configura timeout.
5. Maneja errores.
6. Retry solo cuando sea seguro.
7. Considera idempotencia.
8. Valida datos externos.
9. No expongas secretos en logs.
10. Define comportamiento ante caída del proveedor.
