# git-checkpoint

1. `git status`.
2. `git diff`.
3. Detecta secretos/cambios accidentales.
4. Agrupa unidades lógicas.
5. Verifica pruebas si corresponde.
6. Stagea solo cambios relacionados.
7. Genera mensaje desde el diff.
8. Commit en español.
9. Confirma hash/estado final.

No hacer push.
