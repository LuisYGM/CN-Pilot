# Commit

1. `git status`.
2. Revisa `git diff` y `git diff --staged`.
3. No uses la conversación como única fuente.
4. Excluye secretos, temporales y cambios no relacionados.
5. Separa unidades lógicas si hace falta.
6. Stagea la unidad seleccionada.
7. Crea el commit.

Tipos: `feat`, `fix`, `style`, `refactor`, `perf`, `seo`, `content`, `docs`, `test`, `chore`.

La descripción debe estar siempre en español.

No hagas push.
