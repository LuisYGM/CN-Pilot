# Debug

1. Carga `systematic-debugging`.
2. Define síntoma y entorno.
3. Delega al especialista adecuado.
4. Reproduce/delimita.
5. Recopila evidencia antes de editar.
6. Identifica causa raíz.
7. Implementa corrección mínima.
8. Verifica caso original.
9. Verifica regresiones.
10. Si el impacto lo justifica, delega review.
11. Prepara checkpoint si queda completado.
