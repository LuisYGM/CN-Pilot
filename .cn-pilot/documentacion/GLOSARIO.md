# Glosario breve

- **Agente:** especialista de CN Pilot que coordina o realiza un tipo de trabajo. Jefe de proyecto es la entrada normal.
- **Artefacto:** entregable auxiliar, como contenido, diseño, especificación o informe. No necesariamente es el producto final.
- **Approved / Strict:** referencia visual con autoridad aprobada; Strict pide fidelidad especialmente cercana. Cuanta más autoridad tiene la referencia, menos libertad de rediseño.
- **Checkpoint:** estado local resumido para recuperar una tarea larga si la sesión se interrumpe. No significa que el trabajo continúe en segundo plano.
- **Core:** archivos reutilizables de CN Pilot: documentación, configuración, agentes, skills, comandos y updater.
- **Existing:** proyecto ya implementado. Se parte de sus fuentes actuales y se conserva lo que no esté dentro del cambio autorizado.
- **Flagship:** página de referencia de alta fidelidad que fija cómo se ve y se comporta la dirección antes de implementarla o extenderla.
- **Greenfield:** proyecto nuevo, sin una implementación vigente que haya que preservar.
- **Project Context:** información durable del proyecto en archivos raíz como `PROYECTO.md` y `REQUISITOS.md`.
- **Product / producto:** implementación activa del sitio o aplicación, separada de los outputs auxiliares.
- **Recurso:** input original recibido, por ejemplo un brief, una foto o una referencia visual.
- **Skill:** procedimiento especializado que un agente consulta cuando el trabajo lo requiere.
- **UI Kit:** sistema compartido de decisiones visuales —tipografía, colores, spacing, controles y, cuando aplica, media/motion—. No es una Home ni una página de producto.
- **Worktree:** checkout Git separado que permite trabajar aislado en una rama. Se usa solo para unidades de escritura realmente independientes.
