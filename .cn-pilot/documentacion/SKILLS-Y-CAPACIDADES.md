# Skills y capacidades

Las skills son procedimientos especializados que los agentes de CN Pilot cargan bajo demanda según el objetivo, el stack y el riesgo. **No tienes que elegirlas ni aprender sus nombres.** Esta página solo permite descubrir qué áreas existen; las instrucciones de implementación pertenecen a cada `SKILL.md`.

## Dirección, producto y contenido

| Skill | Área que atiende |
|---|---|
| `product-discovery` | Comportamiento de producto cuando outcome, actores o flujos están abiertos. |
| `web-strategy` | Oferta, audiencia, conversión y arquitectura de información de una web. |
| `content-page` | Estructura y redacción de páginas web. |
| `content-blog-seo` | Investigación y redacción de artículos/editorial SEO. |
| `technical-seo` | Rastreo, indexación, metadata y SEO técnico. |
| `creative-web-experience` | Exploración de dirección creativa para web pública nueva o rediseño material. |
| `application-ui` | Interfaces de aplicaciones, dashboards y estados de producto. |
| `page-composition` | Composición y secuencia de una página concreta. |
| `ui-design-system` | Coherencia de dirección visual y sistema de diseño. |
| `ui-kit-construction` | Foundations, tokens y specimens operativos de un UI Kit. |
| `visual-art-direction` | Lenguaje visual, selección y uso de medios. |
| `form-experience` | Flujo, campos, validación y estados de formularios materiales. |

## Frontend y experiencia

| Skill | Área que atiende |
|---|---|
| `frontend-architecture` | Organización y responsabilidades de frontend custom. |
| `frontend-responsive` | Layout y comportamiento responsive del cambio afectado. |
| `motion-interaction` | Interacciones y motion más allá del CSS trivial. |
| `visual-parity-review` | Comparación técnica con referencia aprobada. |
| `accessibility-review` | Evaluación de accesibilidad sobre una superficie aplicable. |
| `performance-review` | Diagnóstico de rendimiento con síntoma o medición real. |
| `webapp-testing` | Comportamiento de aplicaciones en navegador/runtime. |
| `bricks` | Implementación en Bricks cuando el proyecto lo usa. |
| `elementor` | Implementación en Elementor cuando el proyecto lo usa. |

## Ingeniería e integración

| Skill | Área que atiende |
|---|---|
| `api-integration` | Consumo o exposición real de APIs/webhooks. |
| `auth-access-control` | Autenticación y reglas de autorización. |
| `automation-integrations` | Jobs, eventos y automatizaciones técnicas. |
| `analytics-instrumentation` | Medición técnica de eventos y conversiones cuando está en scope. |
| `database-migrations` | Cambios de schema/datos persistentes con riesgo de migración. |
| `security-review` | Revisión de seguridad por riesgo y superficie real. |
| `systematic-debugging` | Diagnóstico de bugs y comportamiento inesperado antes del fix. |
| `testing-strategy` | Elección y ejecución de pruebas proporcionales. |
| `source-grounded-development` | Verificación en fuentes primarias cuando cambia materialmente la implementación. |

## WordPress

| Skill | Área que atiende |
|---|---|
| `wordpress` | APIs Core, lifecycle y operación de WordPress. |
| `wordpress-theme-development` | Arquitectura de themes Classic, Hybrid o Block. |
| `wordpress-plugin` | Plugins propios y funcionalidad durable de WordPress. |
| `wordpress-content-modeling` | CPT, taxonomías, fields y modelo editorial. |
| `woocommerce` | Catálogo, carrito, checkout y lifecycle de WooCommerce. |
| `deploy-wordpress` | Preparación/ejecución de deployment WordPress autorizado. |

## Operaciones y mantenimiento

| Skill | Área que atiende |
|---|---|
| `existing-site-audit` | Baseline read-only cuando un Existing desconocido condiciona el trabajo. |
| `maintenance-operations` | Coordinación de incidentes, mantenimiento y recuperación material. |
| `release-deployment` | Preparación de release/deployment no WordPress. |
| `git-checkpoint` | Preparación de commit local seguro y acotado. |

Los agentes siguen siendo la entrada práctica. La política de ownership y triggers se mantiene en los prompts y procedimientos del Core; este índice no los reemplaza ni promete que una integración esté instalada.
