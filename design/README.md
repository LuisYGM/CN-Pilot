# Diseño

Especificaciones visuales y referencias cuando se necesiten.

Ubicaciones canónicas:

```text
design/
├── DESIGN-SYSTEM.md
├── COMPONENTS.md
├── pages/          # Prototipos de interfaz web HTML/CSS/JS y especificaciones de páginas
└── references/
```

Los prototipos high-fidelity web se guardan como HTML/CSS/JS responsive real; no como capturas de desktop/mobile. Logos, fotos, SVG, iconos y otros assets se permiten cuando forman parte del diseño. Figma es referencia opcional, no requisito.

Si existe Figma, documentar archivo/página/frame sin secretos.
