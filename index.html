01 / El cambio

Menos dirigir agentes.
Más avanzar en tu proyecto.

El trabajo con IA no debería empezar con un formulario técnico ni una lista de agentes. CN Pilot entiende el contexto antes de preguntar, resuelve los detalles reversibles y deja contigo las decisiones que realmente importan.

02 / Un proceso flexible

Un equipo coordinado.
No una cadena rígida.

La petición define el camino. Cada fase entra cuando ayuda; ninguna es un peaje obligatorio.

  1. 01

    Cuéntalo como eres

    Una frase basta para empezar. Dev Lead revisa lo que ya se sabe y pregunta solo por lo que podría cambiar el resultado.

    ↗
  2. 02

    Contexto antes que suposiciones

    Proyecto nuevo o existente: se localizan las fuentes vigentes y se preserva lo que ya funciona. El proveedor y el modelo se configuran directamente en Kilo.

    ⌕
  3. 03

    Diseño e implementación, con intención

    Si el diseño forma parte del alcance, puedes revisarlo antes de construir. Si pides una mejora puntual, el proceso no se infla.

    ⌘
  4. 04

    Verifica y entrega donde acordaste

    QA proporcional al cambio. El resultado puede ser diseño, código, contenido o handoff; publicar requiere autorización aparte.

    ✓

06 / Compatibilidad actual

Nativo en Kilo.
Honesto con lo demás.

El harness está hecho para Kilo Code. La elección de proveedor y modelo dentro de Kilo es tuya y no está fijada por CN Pilot.

Kilo CodeNativo / soportado
Modelos y proveedores en KiloConfigurables en Kilo
Claude Code · Codex · Cursor · GeminiSin adapter nativo todavía

Algunos archivos pueden inspeccionarse o aprovecharse manualmente en otros entornos. Eso no equivale a integración ni soporte de runtime.

09 / Estado y transparencia

Un producto en evolución, sin claims inflados.

CN Pilot es un harness especializado en proyectos web, human-first y nativo de Kilo Code. No ofrece hoy adapters nativos para otros runtimes. Su documentación principal está en español. El repositorio usa la licencia GNU GPL-3.0-or-later.
