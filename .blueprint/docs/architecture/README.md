# Arquitectura

Guardar aquí documentación de arquitectura suficientemente importante para persistir. No crearla para ajustes triviales.

Las propuestas con incógnitas capaces de cambiar materialmente la arquitectura deben marcarse `PROVISIONAL` e indicar qué falta confirmar. Las recomendaciones provisionales permanecen aquí hasta estar suficientemente establecidas para `DECISIONS.md` o un ADR.
